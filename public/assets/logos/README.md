# Logos

Brand marks shown in the "Works with the tools you already use" row on the
home page.

The SVG files come from [Simple Icons](https://simpleicons.org) 16.38.0, whose
icon data is released under CC0. The marks themselves remain trademarks of
their owners; they are used here only to name products Nelview works with.
Check each owner's brand guidelines before using a mark anywhere else.

Not available from that library, so still shown as text on the page:
Crossref, Microsoft Word, DOAJ, COPE, AJOL. Add an official SVG here and
reference it from `src/pages/index.html` to replace the text.
